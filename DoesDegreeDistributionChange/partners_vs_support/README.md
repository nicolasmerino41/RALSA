# Regional partners versus interaction support

Each point is one species–interaction combination. X is the species' number of regional partners; Y is the number of distinct sites supporting that interaction, K. All ten datasets are shown, coloured by dataset. Axes are linear and identical across panels; points are not jittered or averaged, so identical coordinates overlap.

The combined panel contains both endpoints of each link: once with its consumer's degree and once with its resource's degree. It is not a set of independent links.
