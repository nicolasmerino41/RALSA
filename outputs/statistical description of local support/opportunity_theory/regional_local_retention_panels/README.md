# Regional and local retention

Retention version of regional_local_loss_panels.jl, using the same saved empirical curves in opportunity_theory/conditioned_M/curves.csv (Common rows, whose empirical values are repeated across models). Regional retention is relative to initial regional links L; local retention is relative to initial total interaction occurrences M. Mean gap labels are arithmetic means over integer removal levels m/N <= 0.8, including zero, in percentage points. No refitting or simulations. Existing loss figures are preserved.
