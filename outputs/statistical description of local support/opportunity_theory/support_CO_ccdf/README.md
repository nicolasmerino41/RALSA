# Support and co-occurrence distributions

Empirical complementary cumulative distributions P(K≥x) and P(C≥x) for the SAME known regional interaction pairs (K>0), separately for ten datasets. Co-occurring pairs never observed interacting are excluded. Log-log and linear-axis versions are provided. Lines join observed integer values, matching the requested historical degree-distribution style; no model fitting. Panel x ranges adapt to each dataset. A horizontal shift is a scale difference, not necessarily a shape difference. Since K≤C for every pair, the C curve must be at least as high at a common threshold. Existing confirmed-occurrence provenance and flags from opportunity_support_organisation apply unchanged.
