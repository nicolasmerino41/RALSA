# Regional and local loss

Exact expected loss under uniform removal of a fixed number of sites, using the saved empirical gap curves (the empirical column is repeated across models; Common rows are used once). Regional loss is relative to initial unique links L; local occurrence loss is relative to initial total support M. Both increase from 0 to 100%. Shading spans their difference. Panel annotations use the established arithmetic mean of gap over integer removal levels m/N≤0.8, including zero, in percentage points. This is the established mean-gap summary, not a continuous integrated area. Curves cover 0–100%. No simulations or model refits.
