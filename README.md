# RALSA

**Regional and Local Support Analysis** examines how site loss changes the spatial
support of ecological interactions, their regional persistence, and the interaction
portfolios of generalists and specialists across ten empirical networks.

## Reproduce the figures

Install Julia 1.12. From this repository, run:

```sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia --project=. scripts/run_all.jl
```

The first command installs the pinned dependencies. The second validates the supplied
input tables, computes the analyses and exports PNG, PDF and SVG figures. Paths are
resolved relative to the repository, not the working directory.

To redraw figures after changing their appearance:

```sh
julia --project=. scripts/run_all.jl --figures-only
```

Use `--analysis-only` to compute tables without rendering. Individual analysis and
figure files define functions; `run_all.jl` loads and calls them in order.

## Organisation

- `data/raw/`: frozen, normalised input tables; see [data provenance](data/README.md).
- `data/processed/`: validated inputs generated by the pipeline.
- `scripts/`: data preparation and analyses.
- `src/`: shared loading, removal calculations, configuration and figure style.
- `figures/`: editable figure scripts and reserved conceptual/supplementary folders.
- `outputs/tables/`: numerical results underlying the figures.
- `outputs/figures/main/`: manuscript figures.

Dataset order, removal levels, seed and replicate count are in `src/config.jl`.
Colours and typography are in `src/figure_style.jl`. Supplementary analyses are not
included yet. Figure definitions and assumptions are in [METHODS.md](METHODS.md).

The pipeline starts from the supplied normalised tables and does not require the
earlier working repository or R. The input snapshots retain the earlier study's
occurrence definitions; they are not new independent species surveys.
